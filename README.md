# Шумоподавление и контраст: Gaussian / Median / HE / CLAHE

Базовый пайплайн обработки изображения с оценкой **PSNR** и **SSIM** на синтетическом гауссовом шуме.

Исходное изображение: `data/input.webp` (740×493, скопировано из `F:\i.webp`).

## Что делает скрипт

1. Загружает цветное изображение и переводит его в пространство **LAB**.
2. Добавляет гауссов шум к каналу яркости **L**:
   `sigma = 5, 10, 15, 20, 25, 30, 35, 40`.
3. Обрабатывает зашумлённый канал L методами:
   - **Gaussian** — размытие по Гауссу, ядро 5×5;
   - **Median** — медианный фильтр, ядро 5×5;
   - **HE** — глобальное выравнивание гистограммы;
   - **CLAHE** — адаптивное выравнивание, `clipLimit=2.0`, тайлы 8×8;
   - **Gaussian+HE**, **Gaussian+CLAHE**, **Median+HE**, **Median+CLAHE** — практические связки «шумоподавление → контраст».
4. Считает PSNR и SSIM обработанного канала L относительно чистого L.
5. Строит график PSNR/SSIM от уровня шума и сохраняет визуальную сетку результатов.
6. Дополнительно сохраняет улучшенную версию исходного изображения: Median 3×3 + CLAHE.

## Методика оценки

- Шум аддитивный гауссов, с нулевым средним и стандартным отклонением `sigma`.
- Для каждого `sigma` создаётся отдельное зашумлённое изображение (seed фиксирован, поэтому результат воспроизводим).
- PSNR и SSIM считаются по каналу яркости L, `data_range=255`.
- PSNR/SSIM сравнивают результат с **чистым исходным** изображением. Поэтому методы, которые намеренно меняют кривую яркости (HE, CLAHE), получают низкие абсолютные значения: метрика штрафует не только шум, но и изменение тона/контраста. Это не ошибка, а важная особенность интерпретации.

## Результаты

Средние значения по всем уровням шума:

| Метод | Средний PSNR, дБ | Средний SSIM |
|---|---:|---:|
| Gaussian | **28.49** | **0.691** |
| Median | 27.19 | 0.638 |
| HE | 14.66 | 0.234 |
| CLAHE | 14.59 | 0.235 |
| Gaussian+HE | 16.01 | 0.470 |
| **Gaussian+CLAHE** | **18.91** | **0.507** |
| Median+HE | 15.89 | 0.440 |
| Median+CLAHE | 18.87 | 0.459 |

Крайние точки:

| Метод | PSNR при σ=5 | PSNR при σ=40 | SSIM при σ=5 | SSIM при σ=40 |
|---|---:|---:|---:|---:|
| Gaussian | 30.82 | 25.84 | 0.863 | 0.513 |
| Median | 28.74 | 25.31 | 0.782 | 0.484 |
| HE | 16.30 | 13.01 | 0.513 | 0.112 |
| CLAHE | 19.07 | 11.59 | 0.543 | 0.101 |
| Gaussian+CLAHE | 20.17 | 17.49 | 0.790 | 0.309 |
| Median+CLAHE | 19.95 | 17.57 | 0.705 | 0.281 |

## Выводы

1. **Gaussian 5×5** — лучший метод по PSNR/SSIM на всём диапазоне σ. Для аддитивного гауссова шума линейное сглаживание ожидаемо работает лучше медианы. При σ = 5 PSNR = 30.82 дБ, при σ = 40 — 25.84 дБ.
2. **Median 5×5** немного уступает по PSNR/SSIM, но лучше сохраняет границы и мелкие детали; его преимущество проявляется на импульсном шуме (в этом эксперименте не моделировался).
3. **HE и CLAHE по отдельности** — это методы контраста, а не шумоподавления. На зашумлённом изображении они усиливают шум, поэтому их PSNR/SSIM относительно чистого оригинала низкие (около 11–19 дБ). При малом шуме CLAHE аккуратнее HE (19.07 против 16.30 дБ при σ = 5), при сильном шуме глобальное HE немного устойчивее.
4. **Практический пайплайн**: сначала шумоподавление, затем CLAHE. Лучшие связки в среднем — `Gaussian+CLAHE` (18.91 дБ, SSIM 0.507) и `Median+CLAHE` (18.87 дБ, SSIM 0.459). Они заметно превосходят HE/CLAHE без предварительного сглаживания.
5. Итоговая рекомендация для гауссова шума: **Gaussian 5×5 → CLAHE**. Если важнее сохранить резкие границы или ожидается импульсный шум — **Median → CLAHE**.

## Ограничения

- Оценка PSNR/SSIM «против чистого» полезна для шумоподавления, но не является полноценной метрикой перцептивного контраста. Для контрастных методов имеет смысл дополнительно смотреть гистограмму, энтропию, локальный контраст и визуальное сравнение.
- Параметры фильтров фиксированы (5×5, CLAHE 2.0/8×8). При других размерах ядра или `clipLimit` абсолютные значения изменятся.
- Моделируется только гауссов шум. Импульсный (salt-and-pepper), пуассоновский и реальный сенсорный шум могут дать другой рейтинг методов.
